# 🌤️ Weather App

A responsive React SPA that delivers real-time weather data with a beautiful,
dynamic UI that changes based on current weather conditions.

## ✨ Features

- 🔍 Search weather by any city name
- 🏙️ Quick-select buttons for 6 major Indian cities
  (Mumbai, Delhi, Bangalore, Chennai, Kolkata, Hyderabad)
- 🌡️ Toggle between °C and °F
- 💧 Humidity, wind speed, visibility & feels-like stats
- ⏱️ 4-hour forecast
- 🎨 Dynamic background that changes based on weather
  (sunny, rainy, stormy, cloudy, snowy, etc.)
- ⚡ Built with React + Vite for fast performance

## 🛠️ Tech Stack

- React 19
- Vite 8
- OpenWeatherMap API
- JavaScript (ES6+)
